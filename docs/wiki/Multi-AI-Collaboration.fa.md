# تعامل با سایر هوش‌های مصنوعی، باگ‌یابی و خودبهبودبخشی (Multi-AI Collaboration) 🌐🧠

[English Version](Multi-AI-Collaboration.en.md) | **نسخه فارسی**

دستیار نوا علاوه بر استفاده از موتور هوش مصنوعی مرکزی خود، قادر است با سایر مدل‌ها و سرویس‌دهنده‌های هوش مصنوعی (مانند OpenAI، Claude، DeepSeek، یا مدل‌های محلی آفلاین Ollama) به عنوان **همکار و بازبین فنی (Peer Reviewer)** تعامل کند، کدهای خود را به نقد بگذارد، باگ‌های پنهان را پیدا کند و تجربیات آموخته‌شده را برای همیشه در بانک قوانین یادگیری خود ذخیره نماید.

---

## ۱. سرویس‌دهنده‌های تحت پشتیبانی (Supported Peer Providers)

دستیار نوا از استانداردترین رابط‌های ارتباطی استفاده می‌کند:

| سرویس‌دهنده | مدل‌های پیشنهادی | نوع ارتباط | هزینه / نیازمندی |
| :--- | :--- | :--- | :--- |
| **Ollama** | `llama3`, `mistral`, `deepseek-r1`, `qwen2.5-coder` | `http://localhost:11434/api/chat` | **کاملاً رایگان و آفلاین** (بدون نیاز به کلید API) |
| **OpenAI** | `gpt-4o`, `gpt-4o-mini`, `o1-preview` | `/v1/chat/completions` REST API | نیازمند OpenAI API Key |
| **Anthropic Claude** | `claude-3-5-sonnet-20241022` | `/v1/messages` REST API | نیازمند Anthropic API Key |
| **DeepSeek** | `deepseek-chat`, `deepseek-reasoner` | `/v1/chat/completions` API | نیازمند DeepSeek API Key |
| **OpenRouter** | چندمدلی فراگیر (Llama, Gemini, Mistral) | `/api/v1/chat/completions` | نیازمند OpenRouter Key |
| **Gemini Peer** | `gemini-2.5-flash`, `gemini-2.0-pro` | کلاینت محلی `google-genai` | کلید ثانویه جمینای برای راستی‌آزمایی مستقل |

## ۲. سناریوهای کلیدی تعامل و یادگیری

### ۱. بازبینی کد و باگ‌یابی متقابل (`review_code_with_peer`)
پیش از اجرای اسکریپت‌های حساس سیستم‌عامل یا هنگام توسعه برنامه‌های پیچیده، نوا می‌تواند کد را برای هوش مصنوعی همکار ارسال کند:
- یافتن باگ‌های زمان اجرا و سناریوهای مرزی (Edge Cases).
- کشف رخنه‌های امنیتی، مشکلات مجوزها و فرار از رشته‌ها در ویندوز.
- بررسی نشت منابع و فراموشی در بستن فایل‌ها یا اتصالات شبکه.

### ۲. تقطیر و ثبت درس‌های آموخته‌شده (`learn_from_peer_ai`)
هرگاه هوش مصنوعی همکار پیشنهاد اصلاحی ارزشمندی ارائه دهد:
- این پیشنهاد مستقیماً به یک **قانون طلایی** تبدیل می‌شود.
- این قانون با برچسب `[درس آموخته‌شده از هوش مصنوعی همکار]` در [data/learnings.json](file:///c:/Users/Taimazus/Desktop/MyAgent/data/learnings.json) ثبت می‌شود.
- در کلیه تعاملات بعدی، این قانون به پرامپت سیستمی تزریق می‌شود تا اشتباه هرگز تکرار نشود.

### ۳. حلقه خودبهبودبخشی مستمر (`run_self_improvement`)
نوا می‌تواند به صورت خودمختار یا با درخواست کاربر:
- قوانین فعلی و خطاهای گذشته خود را به هوش مصنوعی ناظر ارائه دهد.
- نقاط کور (Blind Spots) شناختی یا فنی خود را بررسی کند.
- برنامه بهبود عملیاتی شامل راهکارهای عملی را در [data/peer_insights.json](file:///c:/Users/Taimazus/Desktop/MyAgent/data/peer_insights.json) آرشیو کند.

## ۳. نحوه استفاده از پنجره تنظیمات

1. پنجره چت را باز کرده و روی آیکون چرخ‌دنده `⚙️` کلیک کنید.
2. به تب **«🌐 هوش‌های مصنوعی همکار»** بروید.
3. سرویس‌دهنده مورد نظر را انتخاب کنید:
   - اگر از **Ollama** استفاده می‌کنید، نیازی به وارد کردن کلید API نیست.
   - برای سایرین کلید مربوطه را در فیلد کلید API وارد کنید.
4. با زدن دکمه **«🧪 تست اتصال (Ping)»** ارتباط را بسنجید.
5. دکمه **«🔍 باگ‌یابی و بازبینی کد»** را برای مشاهده نمونه بازبینی کد بزنید.
6. با کلیک روی **«💡 ثبت مستقیم این تحلیل به عنوان قانون یادگیری»**، رهنمودها را برای همیشه در حافظه یادگیری دائمی دستیار ثبت فرمایید!
