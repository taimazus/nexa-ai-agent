# ابزارها و قابلیت‌های سیستم‌عامل (Tools & OS Capabilities) 🛠️

[English Version](Tools-and-Capabilities.en.md) | **نسخه فارسی**

دستیار هوشمند **«نِکسا» (NexA AI)** محصول شرکت **راهکار الکترونیک سهند** ([irres.ir](https://irres.ir)) بر خلاف مدل‌های زبانی صرفاً گفتگو‌محور، مجهز به یک **جعبه‌ابزار مستقل و خودکار (Autonomous Agent Toolset)** است. نِکسا می‌تواند مستقیماً روی ویندوز فرامین را اجرا کند، نرم‌افزارها را کنترل نماید، با ایمیل و شبکه‌های اجتماعی ارتباط برقرار کند و سخت‌افزار را مانیتور سازد.

---

## ۱. فهرست کامل ابزارهای هوش مصنوعی نِکسا

### ۱.۱. ابزارهای هسته سیستم و چندرسانه‌ای (Core & Multimodal)
| نام ابزار | ورودی‌ها | عملکرد و کاربرد در سیستم‌عامل |
| :--- | :--- | :--- |
| **`execute_powershell`** | `command`, `timeout_seconds` | اجرای مستقیم فرامین PowerShell و CMD در محیط ویندوز با انکودینگ اجباری UTF-8 جهت پشتیبانی کامل از متون فارسی. |
| **`execute_python`** | `code`, `timeout_seconds` | اجرای اسکریپت‌ها، محاسبات پیچیده ریاضی و پردازش داده در ساب‌پراسس ایزوله پایتون. |
| **`file_operations`** | `action`, `path`, `content` | مدیریت جامع فایل‌ها: خواندن (`read`)، نوشتن (`write`)، الحاق (`append`)، لیست کردن پوشه (`list_dir`)، بررسی وجود (`exists`) و حذف ایمن (`delete`). |
| **`system_diagnostics`** | _بدون ورودی_ | استخراج مشخصات سیستمی: نسخه ویندوز، معماری پردازنده، میزان رم مصرفی و فضای خالی درایوها. |
| **`open_app_or_url`** | `target` | باز کردن نرم‌افزارها (Notepad, Calculator, VS Code و...) یا وب‌سایت‌ها در مرورگر پیش‌فرض سیستم. |
| **`fetch_url`** | `url`, `timeout_seconds` | بارگیری صفحات وب، پاکسازی اسکریپت‌ها و استخراج محتوای متنی تمیز جهت تحلیل هوش مصنوعی. |
| **`capture_screenshot`** | `save_path` (اختیاری) | تصویربرداری بلادرنگ از صفحه‌نمایش برای درک بصری وضعیت دسکتاپ کاربر. |
| **`capture_webcam`** | `camera_index`, `save_path` (اختیاری) | اتصال به وب‌کم با OpenCV، ثبت فریم و ذخیره عکس برای تشخیص محیط یا کاربر. |

### ۱.۲. ابزارهای اکوسیستم خانواده نِکسا (Family Ecosystem & Customization)
| نام ابزار | ورودی‌ها | عملکرد |
| :--- | :--- | :--- |
| **`switch_family_member`** | `member_name` | سوئیچ آنی به ایجنت دیگر خانواده (نِکسامِهر، نِکسانو، سامیار، آرتین، نیلا، تارا، پارسا). |
| **`customize_family_member`** | `name`, `display_name_fa`, `gender`, `mood`, `avatar_style`, ... | ویرایش ویژگی‌های شخصیتی، سبک رفتاری، صدا و آواتار هر عضو بر اساس سلیقه کاربر. |
| **`teach_family_skill`** | `member_name`, `skill_name`, `steps` | آموزش فرآیند جدید به عضو خانواده با ثبت امتیاز تجربه (XP) و ثبت در حافظه پایدار. |
| **`add_family_member`** | `name`, `display_name_fa`, `role`, `personality`, ... | ایجاد و ثبت یک عضو هوشمند جدید در خانواده نِکسا. |
| **`list_family_members`** | _بدون ورودی_ | دریافت مشخصات تمامی اعضای فعال خانواده، وضعیت تجربه و سطوح مهارتی. |

### ۱.۳. ابزارهای کنترل نرم‌افزارها و یادگیری ماکرو (Universal App Automation)
| نام ابزار | ورودی‌ها | عملکرد |
| :--- | :--- | :--- |
| **`inspect_app_ui`** | `window_title`, `control_type` | کاوش سلسله‌مراتب کنترلی پنجره با Windows UI Automation (دکمه‌ها، ورودی‌های متن، منوها، چک‌باکس‌ها). |
| **`invoke_app_element`** | `window_title`, `element_name`, `control_type`, `action` | کلیک و فراخوانی خودکار روی المان‌های برنامه‌های ویندوزی بدون دخالت کاربر. |
| **`learn_app_workflow`** | `workflow_name`, `app_name`, `steps`, `description` | ذخیره یک فرآیند کاری چندمرحله‌ای برای استفاده‌های بعدی در قالب ماکرو. |
| **`execute_app_workflow`** | `workflow_name`, `parameters` | اجرای خودکار یک ماکروی ذخیره‌شده همراه با تزریق متغیرهای پویا (مانند متن یا مسیر فایل). |
| **`list_app_workflows`** | _بدون ورودی_ | مشاهده فهرست تمامی فرآیندهای کاری ذخیره‌شده و توضیحات آن‌ها. |

### ۱.۴. ابزارهای یکپارچه‌سازی ایمیل و اینستاگرام (Email & Instagram Integrations)
| نام ابزار | ورودی‌ها | عملکرد |
| :--- | :--- | :--- |
| **`check_emails`** | `folder`, `limit`, `unread_only`, `search_query` | اتصال به سرور IMAP، استخراج پیام‌ها، اولویت‌بندی بر اساس فوریت و ارائه گزارش صوتی. |
| **`send_email`** | `to_email`, `subject`, `body` | ارسال پیام‌های ایمیلی از طریق سرور SMTP پیکربندی‌شده. |
| **`configure_email_settings`** | `imap_server`, `smtp_server`, `email_address`, ... | پیکربندی مشخصات میل‌سرور از طریق دستیار صوتی. |
| **`plan_instagram_content`** | `topic`, `target_audience`, `content_type` | سناریونویسی ویدیوی ریلز، طراحی بنر پست، کپشن جذاب و هشتگ‌های ترند. |
| **`open_instagram`** | _بدون ورودی_ | باز کردن وب‌سایت اینستاگرام در مرورگر پیش‌فرض کاربر. |
| **`copy_caption_to_clipboard`** | `caption` | کپی فوری متن کپشن در کلیپ‌بورد ویندوز برای تسریع انتشار محتوا. |

## ۲. ایمنی، پایش و یادگیری از خطا (Safety & Sandboxing)
* **تایم‌اوت خودکار:** تمامی دستورات اجرایی دارای محدودیت زمانی پیش‌فرض هستند تا مانع قفل شدن پروسه گردند.
* **تحلیل خطا با موتور یادگیری (`LearningEngine`):** در صورت بروز خطا در اجرای هر ابزار، خطای ثبت‌شده تحلیل شده و راهکار اصلاحی برای دفعات بعدی در پایگاه حافظه ذخیره می‌شود.
